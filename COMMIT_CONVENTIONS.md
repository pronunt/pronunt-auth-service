# Commit Conventions

Use Conventional Commits for this repository.

Format:

`type(scope): short summary`

Examples:

* `feat(auth): add GitHub App token generation`
* `fix(jwt): validate private key loading`
* `refactor(service): simplify auth client flow`
* `docs(readme): update local setup steps`
* `chore(deps): bump cryptography`
* `test(auth): add token service tests`

Recommended types:

* `feat`
* `fix`
* `refactor`
* `docs`
* `chore`
* `test`
* `ci`
* `build`
